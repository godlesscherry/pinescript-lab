# Fractal Tools

Indicator(s) for fractal pivots and related structure. Use as overlay or as building blocks for strategies (e.g. sweep detection in Sweep Scalper).

## Files

- `fractal-template.pine` — Skeleton for fractal-based drawing or signals. Extend with your pivot/sweep logic.

## Usage

Paste into TradingView Pine Editor as an indicator. Can be combined with strategies that need fractal levels or sweep detection.
