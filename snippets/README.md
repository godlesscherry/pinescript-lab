# Snippets

Pine Script code snippets for VS Code / Cursor.

- **pine-strategy** — Strategy file header  
- **pine-indicator** — Indicator file header  
- **pine-input** — Input with group  
- **pine-st** — Supertrend block  
- **pine-bb** — Bollinger Bands block  
- **pine-macd** — MACD block  
- **pine-alert** — alertcondition  
- **pine-entry** — strategy.entry  
- **pine-exit** — strategy.exit (stop/limit)

The same snippets are in `.vscode/pine.code-snippets` so they apply when editing `.pine` files in this workspace. Install a Pine Script extension (e.g. Pine Script Syntax Highlighting) so the `pine` language is recognized.
